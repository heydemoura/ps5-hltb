## Native completion metrics and game-switch stability

Download **hltb.elf** and send it to elfldr. The single payload installs and enables the metrics panel. **hltb-query.elf** is an optional stdout query diagnostic. **SHA256SUMS** covers both files.

- Show Main Story, Main + Extra, and Completionist estimates in one native panel for every matched game, including games without played time.
- Keep the panel visible with Play Game unfocused, using fixed screen placement and consistent native typography, padding, translucent background, and rounded corners. Preserve the original title and played-time controls.
- Fix the repeated game-switch crash by hosting the panel outside React's managed widget tree. Keep one active panel, coalesce navigation events, release old selection handles on the UI thread, and run at most one background lookup at a time.
- Cache all three estimates for 30 days in `/user/hltb/cache.json`. Valid saved results display without another network request and survive reboot. Migrate the previous temporary cache automatically.
- Build and publish release payloads automatically with GitHub Actions. Pull requests run the same build and sanitizer tests.

Validation includes host ASan/UBSan tests for 2,000 game switches, 100,000 coalesced updates, construction failures, and 1,000 network lookups with resource accounting. Console checks on firmware 12.20 confirmed repeated switching and visibility without Play Game focus; the README includes a native ASTRO BOT screenshot.

Only firmware **12.20** has been tested. Estimates depend on HowLongToBeat's unofficial website API and title matching; missing extra/completionist estimates display `N/A`. Restart ShellUI or reboot before loading this version over an older resident payload.
